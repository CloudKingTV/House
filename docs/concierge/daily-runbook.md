# Daily runbook

For the house manager during the live week (14–20 Nov). Print one per day.

## 07:00 · Open
- [ ] Heating on, lights on and shared spaces checked
- [ ] Breakfast set up; today's coffee orders prepared
- [ ] Today's schedule on the board in the kitchen
- [ ] Confirm all cars for today with the chauffeur company
- [ ] Check the weather; umbrellas at the door if needed

## 07:45 · Morning session (if any)
- [ ] Room set 30 min before, with the partner signage placed
- [ ] Guest list at the door
- [ ] Crew set up and mics tested

## 09:15 · Stand-up (10 min, with the content lead)
- [ ] Today's schedule and any changes
- [ ] Content assignments per resident
- [ ] Studio slots confirmed
- [ ] Anything anyone needs today?

## Midday
- [ ] Housekeeping done in every room (check with the housekeeper)
- [ ] Studio running on schedule
- [ ] Deliveries received and checked (flowers, food, kit)

## 17:00 · Evening prep
- [ ] Session room set, with AV and the stream tested
- [ ] Door team briefed: guest list, colour codes, VIPs
- [ ] Hot food ready for residents returning from Olympia

## 21:00 · Briefing
- [ ] Send the [nightly briefing](../guests/daily-briefing-template.md) to the resident group
- [ ] Send personal DMs (studio slots, car times, intros)
- [ ] Print pillow cards

## 22:00 · Turndown
- [ ] Pillow card, water and a small treat in every room
- [ ] Curtains closed, lights low

## 23:00 · Close
- [ ] Recap posted (check with the content lead)
- [ ] Charter compliance updated in `data/guests.json`
- [ ] Issues log reviewed: anything still open gets an owner for the morning
- [ ] Quiet hours from 23:30; doors checked; security handover
