## If something happens
1. **Make people safe first.** Call 999 if in doubt.
2. Tell the house manager and host immediately.
3. Stop filming. No content from an incident, ever.
4. Write down what happened, when and who was involved, the same day.
5. Only the host speaks for the house, to anyone.
